Build a production-quality full-stack e-commerce application called **Smart Product Recommendation System**.

### Goal

Create a modern online store where users can register, browse/search/filter products, purchase products, manage cart/wishlist, review products, and receive personalized recommendations based on their behavior. Build both:

1. Customer E-commerce Platform
2. Admin Dashboard

### Tech Stack

* Frontend: React + Vite + Tailwind CSS + React Router + Axios + Lucide
* Backend: Node.js + Express.js REST API
* Database: PostgreSQL + Prisma
* Auth: JWT + bcrypt
* Charts: Recharts
* Roles: CUSTOMER and ADMIN

### Customer Features

Implement:

* Register/Login/Logout
* Profile and preferences
* Product catalog with categories
* Search, filters and sorting
* Product details and similar products
* Cart and Wishlist
* Checkout with COD + mock online payment
* Orders and order history
* Product ratings/reviews
* Personalized home/dashboard
* Recently viewed, trending, best sellers and recommended products

### Recommendation System

This is the main feature.

Track:

* Product views/clicks
* Searches
* Category visits
* Wishlist
* Cart additions/removals
* Purchases
* Ratings
* Product-page time

Create a `BehaviorEvent` table.

Use a **hybrid recommendation system**:

1. **Content-based** — category, brand, price and product attributes.
2. **Collaborative filtering** — recommend products based on similar users/products.
3. **Popularity-based** — trending, best-selling and highly-rated products for new users.

Behavior weights:
`VIEW=1, CLICK=2, WISHLIST=4, ADD_TO_CART=6, RATING=8, PURCHASE=10`

Recommendation score:
`Behavior Score + Category Similarity + Product Similarity + Popularity + Rating`

Provide recommendation reasons such as:

* "Based on your recent interests"
* "Popular with customers like you"
* "Frequently bought with this product"

APIs:

* `/api/recommendations/user/:userId`
* `/api/recommendations/similar/:productId`
* `/api/recommendations/trending`
* `/api/recommendations/frequently-bought/:productId`
